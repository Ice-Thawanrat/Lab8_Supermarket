# Lab8_Supermarket
ระบบจัดการสินค้า Supermarket

#Features
- แสดงรายการสินค้า
- เพิ่มสินค้า
- แก้ไขสินค้า
- ลบสินค้า
- อัปโหลดรูปสินค้า
- ลบรูปสินค้าเมื่อทำการลบข้อมูล

#Default Functions
Home Page
- แสดงรายการสินค้า
- แสดงรูปสินค้า
- แสดงจำนวนสินค้า

#Add Product
- เพิ่มสินค้าใหม่
- อัปโหลดรูปภาพ

#Edit Product
- แก้ไขข้อมูลสินค้า
- เปลี่ยนรูปสินค้า

#วิธีติดตั้งและรัน
1. Clone Project (git clone https://github.com/Ice-Thawanrat/Lab8_Supermarket.git)
2. เปิดโฟลเดอร์โปรเจกต์ (cd Lab8_Supermarket)
3. ติดตั้ง package (npm install)
4. เปิดโปรแกรม XAMPP แล้วกด Start:
- Apache
- MySQL
5. เข้า phpMyAdmin (http://localhost/phpmyadmin)
6. สร้าง Database ชื่อ supermarket_db
7. Import ไฟล์ supermarket_db.sql
8. รันโปรเจกต์ npm run dev
9. เปิดเว็บไซต์ http://localhost:5000
